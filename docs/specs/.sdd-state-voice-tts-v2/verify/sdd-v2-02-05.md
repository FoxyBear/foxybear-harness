## Notes / deviations

- **SDD-03 (ElevenLabs), SDD-04 (audio sink), SDD-05 (expressivity) are
  deferred** per task scope. Their normative contract is captured by the
  `VoiceEngine` interface + `EngineCapabilities` and verified via
  `InMemoryVoiceEngine`; the real provider modules will implement the same
  surface.
- The tap (SDD-02) is implemented inside `Voice.Service` as a
  `message.part.delta` Bus subscription that forwards to `feedText`, gated on
  `getState().mode === "on"`. No local voice-mode map exists; mode is owned by
  `Voice.Service`.
- Provider substitution (V11) is demonstrated by an offline engine
  (`streaming:false`, `bargeInSupport:"none"`, `flush:false`) operating through
  the identical `VoiceEngine` contract via capability flags.
